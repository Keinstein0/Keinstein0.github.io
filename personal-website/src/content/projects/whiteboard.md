## Whiteboard App

Für eine meiner Lernperioden (gegebene Zeit der Schule für das Arbeiten an inf projekten)
entschied ich mich eine Web-App zu machen, welche es mir erlaubt mittels Handschrift auf
ein virtuelles Whiteboard zu schreiben und dann der Inhalt desjenigen mittels einer OCR
api in saubere Trello Karten einzulesen.
